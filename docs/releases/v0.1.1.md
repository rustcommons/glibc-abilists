# glibc-abilists v0.1.1

glibc-abilists 0.1.1 documents the public records and lookup behavior more fully and adds documentation checks. The ABI dataset and runtime API behavior stay the same.

Original crates.io publication: **2026-10-14 (UTC)**, `2026-10-14T12:00:16.913597Z`.
Source: `v0.1.1` at `d7e5228dae5b2591fc7849a9b82607a7d6bc25bb`. Package `glibc-abilists`
is available on crates.io and was non-yanked when checked on 2026-11-02.
These user-facing notes were backfilled on 2026-11-02; GitHub Release
publication timestamps are separate from the original package date.

## Changes

- Document public signature/license fields and explain `None` for unknown
  release/library lookups.
- Add missing-documentation warnings, README doctests and selected missing-lookup
  tests. CI gains a warning-denied rustdoc job.
- Set the documentation URL and explicit x86_64 Linux docs.rs target; add README
  registry/API navigation and a repository roadmap. This docs.rs setting does
  not add another dataset architecture or a runtime compatibility guarantee.

## Upgrade

No data refresh, application rebuild or downstream minimum requirement change
is needed solely for these documentation additions. Rust 1.90 remains the
minimum; public items and library behavior are unchanged. Existing 0.1.x
requirements can permit this patch, while existing lockfiles retain their
selected version until deliberately updated.

## Validation and limits

The retained release-tag CI run passed docs, Linux/Windows Rust checks, MSRV,
package verification and online collector comparison. The tag diff adds docs,
lints, doctest/test coverage and metadata; data, generated tables, collector,
keys and upstream selection are unchanged from 0.1.0.

These are bounded checks, not universal runtime compatibility qualification.
The exception wording shipped in this version still overstates signature
assurance. It does not reflect an enforced signature-presence/configured-key
match guarantee; 0.1.2 corrects the text without changing that policy.

No original GitHub Release body was found during the 2026-11-02 inventory;
these notes reconstruct the shipped tag and registry version.
